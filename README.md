# Chappal House Atmakur — Website

Premium, animated React/Vite website for Chappal House, a multi-brand footwear
store on Bypass Road, Atmakur (est. 2006).

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```

## Structure

- `src/main.jsx` — the whole single-page site (hero, categories, products, store
  experience, Instagram CTA, contact/visit, footer)
- `src/styles.css` — styling and animations
- `public/assets/` — logo, storefront, interior and product photos used on the site
